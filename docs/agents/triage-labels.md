# Triage labels

Reuse the existing `OVE` labels; do not create duplicates.

| Role | Linear label |
| --- | --- |
| bug | Bug |
| enhancement | Feature |
| needs-triage | needs-triage |
| needs-info | needs-info |
| ready-for-agent | ready-for-agent |
| ready-for-human | ready-for-human |
| wontfix | wontfix |

Apply exactly one category and one triage-state label. Use native blocking relations for dependencies, not labels that ambiguously combine readiness and execution. An agent-ready issue may remain in Backlog until its blockers pass. Do not add invented due dates or estimates. During triage, follow the installed skill's AI-generation disclaimer requirement.
