## What to build

A user explores a relationship or comparison using only the necessary versioned schema and approved operations.

Owner: Shared question routing and both domain adapters.

## Acceptance criteria

- [ ] Build indexes/task slices at schema release and select exact identifiers/templates before model planning.
- [ ] Expose a route receipt with required facets and step/hop/row/token/spend ceilings.
- [ ] Compare SQL and graph results without promising identical backend consistency guarantees.
- [ ] Preserve graph path predicates and supporting assertions; cap-triggered omissions cannot become complete answers.
- [ ] Return needs_budget or unsupported rather than upgrading to Research automatically.
- [ ] Choose the approved native Cypher/named/typed artifact route and preserve native semantics; no mandatory new read DSL and no agent GraphQL adapter.
