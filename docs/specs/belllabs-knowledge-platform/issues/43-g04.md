# G04: Ship a transport-neutral typed GraphQL client for the approved operations

Linear: [OVE-140](https://linear.app/overtonbell/issue/OVE-140/ksp-g04-ship-a-transport-neutral-typed-graphql-client-for-the-approved)

Status: ready-for-agent; implementation not started.

## What to build

Web and Expo consumers can install a versioned package and execute typed approved queries without server dependencies.

Owner: Biotech client package owner.

## Acceptance criteria

- [ ] Generate operation-specific TypedDocumentNode, variables/results, fragments and strict scalar mappings from the executable read schema with deterministic codegen.
- [ ] Export an injected transport/auth supplier, abort/deadline, typed errors and explicit partial-data semantics; retries are bounded eligible reads.
- [ ] Package ESM/types and compatibility metadata; exclude Neo4j/server libraries, Node-only modules, schema snapshots and secrets from runtime exports.
- [ ] Compile and run the packed package outside the monorepo for web and Expo; validate documents and schema compatibility in CI.

## Blocked by

G01, G02, G03

## Testing seam

Exercise the published consumer behavior and actual native adapter at the highest useful seam. Use targeted component, disposable integration and selected-query measurements; complete application fixtures remain restricted to F99.

## Out of scope

Implicit v2 acceptance, unreviewed ontology/vector choices, routing agents through GraphQL, unrelated refactors, and either complete application fixture before F99.
