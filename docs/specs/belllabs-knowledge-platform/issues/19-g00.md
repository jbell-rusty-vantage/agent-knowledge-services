## What to build

An operator can distinguish the deployed API, current graph compatibility and unaccepted v2 candidate from local configuration.

Owner: Biotech GraphQL/Fly operator.

## Acceptance criteria

- [ ] Read back image/release, Machine topology/resources and runtime feature/schema versions through the documented Fly wrapper; report inaccessible evidence explicitly.
- [ ] Reconcile health source digest, executable-schema identity, current graph/index compatibility and local pins without claiming that healthy connectivity proves migration.
- [ ] Inventory current supported consumers/operations and collect a baseline measurement plan with no production load benchmark or index mutation.
- [ ] Correct stale deployment documentation and record source-versus-live evidence with no secrets.
