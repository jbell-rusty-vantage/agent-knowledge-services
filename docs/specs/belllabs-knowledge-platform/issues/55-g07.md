## Acceptance criteria

- [ ] Read actual Machine/Aura topology and benchmark approved load; select memory/heap, shared/performance CPU, locality and replica/pool budgets from evidence.

- [ ] Qualify startup, liveness/readiness, graceful drain, bounded product smoke/canary and old-mobile operation compatibility.
- [ ] Pin image/library/schema/projection/index/auth/registry/SDK versions and document rollback versus forward data repair; no final full application fixture runs here.
