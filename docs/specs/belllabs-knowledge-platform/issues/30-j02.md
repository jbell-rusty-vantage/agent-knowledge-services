Linear: [OVE-104](https://linear.app/overtonbell/issue/OVE-104/ksp-j02-use-a-biotech-jev-recipe-for-scientific-applicability-triage)

Status: ready-for-agent; implementation not started.

## What to build

An installed agent triages study/product/protocol applicability while preserving insufficient evidence and scientific qualifiers.

Owner: Biotech domain skills and Jev consumer.

## Acceptance criteria

- [ ] Specify a closed recipe for material/population/endpoint comparability with domain-owned labels and rubric.
- [ ] Skill distinguishes routing/classification from evidence verification and canonical admission.
- [ ] Demonstrate incomparable formulation, missing dose/context, contradictory evidence and uncertain identity outcomes.
- [ ] Evaluate separately from AI Engineer labels; domain shift cannot reuse confidence thresholds implicitly.
- [ ] Use captured immutable state and explicit escalation to verification or review rather than fallback invented labels.
