# D02: Publish and materialize an exact app-scoped skill bundle

Linear: [OVE-92](https://linear.app/overtonbell/issue/OVE-92/ksp-d02-publish-and-materialize-an-exact-app-scoped-skill-bundle)

Status: ready-for-agent; implementation not started.

## What to build

An authorized publisher registers a proposed capability whose exact bytes can be inspected and materialized by the correct consumer.

Owner: Mission Control catalog/custody owner.

## Acceptance criteria

- [ ] Wire the real custody service through publish/inspect/render public routes; do not rely solely on seed scripts.
- [ ] Upload immutable per-file digest/size manifests to the correct app bucket and register exact version pins.
- [ ] Repeat upload/register is resumable; corruption, foreign application, traversal and external symlinks fail.
- [ ] Prove actual consumer write restrictions and secret-reference projection for each claimed host.
- [ ] Keep proposed/admitted/granted states distinct and never modify immutable released seeds.

## Out of scope
