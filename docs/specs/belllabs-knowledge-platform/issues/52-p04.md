# P04: Accept scoped external-agent progress and artifact handshakes

Linear: [OVE-123](https://linear.app/overtonbell/issue/OVE-123/ksp-p04-accept-scoped-external-agent-progress-and-artifact-handshakes)

Status: ready-for-agent; implementation not started.

## What to build

A user works in their own agent environment and returns attributable progress or research artifacts to the product.

Owner: Product external-consumer adapters.

## Acceptance criteria

- [ ] Issue short-lived audience/actor/content/attempt-scoped handshakes without embedding tokens in skills.
- [ ] Validate bound artifact/test evidence and retain review state; agent completion alone cannot pass grading or publication.
- [ ] Duplicate submission returns the existing receipt; wrong audience/tenant or changed bytes fail.
- [ ] Expose receipt lookup and progress through product API and external MCP/CLI guidance.
- [ ] Cover one learning attempt and one saved-research artifact without running the final full app workflows.
- [ ] Register and qualify the handshake/progress/test capability delta in each app catalog after the base assembly, and reconcile the final assembly digest before D06.
- [ ] Launch or link a real supported editor/workspace with the pinned challenge/project and return trusted test artifacts; building a full embedded IDE is outside this release.

## Blocked by

P01, P02, D03, D04

## Testing seam

Exercise the published consumer behavior and actual native adapter at the highest useful seam. Use targeted component, disposable integration and selected-query measurements; complete application fixtures remain restricted to F99.

## Out of scope

Unrelated refactors, accepting the entire Biotech ontology, altering immutable historical receipts, and running either complete application fixture before F99.
