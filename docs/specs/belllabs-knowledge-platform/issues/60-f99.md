- [ ] Admission checks every prerequisite issue and release evidence; one open, failed or unqualified mandatory prerequisite blocks both fixtures.

- [ ] Report correctness, evidence coverage, latency and full cost with passed/failed/blocked/unrun distinctions; a failure reopens its owning issue before a final rerun.
- [ ] No complete application fixture executes during earlier slices; component tests, frozen quality evaluations and disposable adapter checks remain required throughout.
- [ ] Exercise product Biotech GraphQL/typed client and native agent tools as distinct paths, plus AI Engineer custom API; no agent GraphQL substitution.
- [ ] Every mandatory Q/G/N decision and implementation slice must be complete; unresolved owner decisions block both complete fixtures.
