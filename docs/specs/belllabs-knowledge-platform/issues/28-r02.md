Linear: [OVE-97](https://linear.app/overtonbell/issue/OVE-97/ksp-r02-answer-familiar-biotech-questions-through-bounded-graph-and)

Status: ready-for-agent; implementation not started.

## What to build

A consumer resolves a public entity and gets a scoped answer grounded in graph assertions and retained sources.

Owner: Biotech domain service.

## Acceptance criteria

- [ ] Direct routes use native bounded resolve/card/trace queries and preserve hu identifiers.
- [ ] Add an evidence retrieval contract that returns source snapshots/locators, assertion qualifiers and scoped omissions.
- [ ] Approved scientific comparison patterns preserve population/material/dose/context rather than treating adjacency as support.
- [ ] Implement application/tenant access plus cost/row/hop/time caps without exposing unrestricted generated mutations.
- [ ] Measure fixed questions and authority-aware cache invalidation; missing evidence remains explicit.
- [ ] Use the approved native agent read path, preserving current pinned-schema support without requiring v2 for ordinary reads; product entity clients use the separate GraphQL track.
- [ ] New Biotech corpus/vector/GraphRAG behavior belongs to Q03/N04/N05; until qualified return unsupported rather than implying vector or evidence-channel completeness.
