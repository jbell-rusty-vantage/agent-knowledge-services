# C01: Create and publish an evidence-bound AI Engineer learning artifact

Linear: [OVE-110](https://linear.app/overtonbell/issue/OVE-110/ksp-c01-create-and-publish-an-evidence-bound-ai-engineer-learning)

Status: ready-for-agent; implementation not started.

## What to build

An author creates a versioned lesson/challenge/project draft, validates its learning and runnable properties, and publishes the exact reviewed version.

Owner: AI Engineer content and product owners.

## Acceptance criteria

- [ ] Keep private drafts separate from official knowledge and require expected revision/idempotency.
- [ ] Bind learning objectives, prerequisites, claims, sources and runnable test/rubric versions.
- [ ] Use assertion census and verification admission; model praise cannot replace deterministic project tests.
- [ ] Review and publication bind exact content/evidence versions; post-review edits invalidate approval.
- [ ] Expose draft/read/revise/submit-review on API, MCP and CLI. Official publish/withdraw use authorized reviewer HTTP/CLI; ordinary MCP returns its explicit publication exclusion. Do not widen existing vector-publication grants.
- [ ] A challenge/project binds a runnable test command and trusted workspace artifact; deterministic test execution, timeout and failure are attributable to its exact content version.
