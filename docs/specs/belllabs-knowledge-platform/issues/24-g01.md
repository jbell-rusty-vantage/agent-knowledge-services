# G01: Export a reviewed executable GraphQL read contract for one product slice

Linear: [OVE-135](https://linear.app/overtonbell/issue/OVE-135/ksp-g01-export-a-reviewed-executable-graphql-read-contract-for-one)

Status: needs-info; implementation not started.

## What to build

A client developer obtains the exact bounded read schema for the accepted first product operations.

Owner: Biotech schema and GraphQL owners.

## Acceptance criteria

- [ ] Derive a versioned read projection from the approved upstream schema with feature/source/executable digests and compatibility metadata; never edit pinned SDL by hand.
- [ ] Inventory type/field query, mutation, nested-operation, filter/sort/select/aggregate and deprecated controls against installed library semantics.
- [ ] Remove unused generated write families and review deprecated/aggregate compatibility; aggregate:false alone must not be claimed to remove aggregation filters.
- [ ] Export the same executable schema used by the server without production secrets/provider calls; validate the first real operations and report build/size evidence separately from database migration.

## Out of scope
