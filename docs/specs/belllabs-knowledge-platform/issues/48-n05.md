# N05: Retrieve scientific evidence through the selected native graph profile

Linear: [OVE-145](https://linear.app/overtonbell/issue/OVE-145/ksp-n05-retrieve-scientific-evidence-through-the-selected-native-graph)

Status: needs-info; implementation not started.

## What to build

A native agent answers the first approved scientific question class with bounded graph context and replayable evidence.

Owner: Biotech retrieval and evaluation owner.

## Acceptance criteria

- [ ] Run selected entity/lexical/vector candidates, bounded graph expansion and evidence resolution through native tools, never GraphQL.
- [ ] Preserve study/population/material/dose/endpoint/time qualifiers, contradictions and source locators; adjacency/similarity is discovery rather than support.
- [ ] Compare approved available baseline channels on frozen questions/evidence for recall, citation/support correctness, cost and latency; unsupported channels remain explicit.
- [ ] Bind corpus/index/model/query versions, ACL/current eligibility and retained result packets; ANN rerun is not exact historical replay.

## Blocked by

N04, N01, F02

## Testing seam

Exercise the published consumer behavior and actual native adapter at the highest useful seam. Use targeted component, disposable integration and selected-query measurements; complete application fixtures remain restricted to F99.

## Out of scope

Implicit v2 acceptance, unreviewed ontology/vector choices, routing agents through GraphQL, unrelated refactors, and either complete application fixture before F99.
