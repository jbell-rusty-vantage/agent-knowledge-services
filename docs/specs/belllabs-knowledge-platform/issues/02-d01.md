# D01: Reconcile a complete per-application capability assembly

Linear: [OVE-89](https://linear.app/overtonbell/issue/OVE-89/ksp-d01-reconcile-a-complete-per-application-capability-assembly)

Status: ready-for-agent; implementation not started.

## What to build

An operator sees every domain skill, MCP server/tool and CLI entrypoint with a truthful registration/readiness disposition.

Owner: Mission Control capability owner and domain release owners.

## Acceptance criteria

- [ ] Inventory owned and vendored domain skills including operational skills, registered tools and binary/subcommand bindings.
- [ ] Map to existing supported asset kinds; design a versioned CLI binding extension only if required.
- [ ] Detect missing/extra/drifted/proposed/admitted/revoked/retired assets and unresolved provider dependencies.
- [ ] Separate public-download guidance from private rubrics and secrets.
- [ ] Produce a read-only deterministic assembly manifest and diff without modifying live catalogs.
- [ ] Inventory owned/vendored Neo4j skills and proprietary native schema/read/ingest contracts; GraphQL is not an agent dependency.

## Blocked by

F01

## Testing seam

Exercise the published consumer behavior and actual native adapter at the highest useful seam. Use targeted component, disposable integration and selected-query measurements; complete application fixtures remain restricted to F99.

## Out of scope

Unrelated refactors, accepting the entire Biotech ontology, altering immutable historical receipts, and running either complete application fixture before F99.
