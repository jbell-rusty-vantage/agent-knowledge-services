# C02: Create and publish an evidence-bound Biotech research artifact

Linear: [OVE-111](https://linear.app/overtonbell/issue/OVE-111/ksp-c02-create-and-publish-an-evidence-bound-biotech-research-artifact)

Status: ready-for-agent; implementation not started.

## What to build

An author creates a report/article/protocol edition or timeline view with explicit scientific context and traceable assertions.

Owner: Biotech content and product owners.

## Acceptance criteria

- [ ] Version domain payloads independently of shared content lifecycle; no whole-ontology acceptance prerequisite.
- [ ] Preserve material, population, dose, duration, endpoint, uncertainty and valid/recorded times where relevant.
- [ ] Keep source fidelity distinct from support/world correctness and require intended-use admission.
- [ ] Publish only exact reviewed versions; withdrawals and supersessions retain historical evidence.
- [ ] Demonstrate one complete content-kind path and validate contract schemas for all declared initial kinds without pretending all UI screens exist.
- [ ] Official publish/withdraw use reviewer-authorized HTTP/CLI with explicit ordinary-MCP exclusion; draft and submit-review remain agent-accessible within grants.

## Blocked by

V07, V02, V05, R02

## Testing seam

Exercise the published consumer behavior and actual native adapter at the highest useful seam. Use targeted component, disposable integration and selected-query measurements; complete application fixtures remain restricted to F99.

## Out of scope

Unrelated refactors, accepting the entire Biotech ontology, altering immutable historical receipts, and running either complete application fixture before F99.
