Linear: [OVE-103](https://linear.app/overtonbell/issue/OVE-103/ksp-j01-use-an-ai-engineer-jev-recipe-in-an-executable-domain)

## What to build

An installed agent classifies a learning/research item with a pinned closed-choice recipe and handles uncertainty correctly.

Owner: AI Engineer domain skills and Jev consumer.

## Acceptance criteria

- [ ] Define one concrete taxonomy/routing recipe with labels, criteria, captured inputs and Noul/insufficient-evidence outcomes.
- [ ] Skill shows actual CLI/MCP invocation, result interpretation, rejected input and escalation.
- [ ] Evaluate recipe on independent labeled cases; raw confidence is not calibrated admission.
- [ ] Persist result/recipe provenance; retries preserve captured input and disclose possible provider rebilling.
- [ ] Keep canonical writes and permissions outside Jev and preserve current queue deployment constraints.
