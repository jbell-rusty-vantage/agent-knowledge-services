# N04: Ingest one approved source into a versioned searchable corpus

Linear: [OVE-144](https://linear.app/overtonbell/issue/OVE-144/ksp-n04-ingest-one-approved-source-into-a-versioned-searchable-corpus)

Status: needs-info; implementation not started.

## What to build

One accepted source becomes eligible for retrieval with traceable representation/chunks and the selected index generation.

Owner: Biotech corpus ingestion/index owner.

## Acceptance criteria

- [ ] Implement the chosen snapshot/text/chunk/locator/entity-link contract with stable IDs, model/chunker/extractor versions and truthful partial-capture handling.
- [ ] If embeddings are selected, validate model/dimensions and index generation/coverage; if excluded, prove the approved lexical/entity route and explicit vector unavailability.
- [ ] Demonstrate graph/index reconciliation, failed indexing, duplicate ingestion, correction, supersession and deletion/replay behavior; no distributed atomicity claim.
- [ ] Promote serving eligibility only after accepted coverage/admission checks; source overlap or MENTIONS is not evidence support.
