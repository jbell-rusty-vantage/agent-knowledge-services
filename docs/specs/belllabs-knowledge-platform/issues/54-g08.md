# G08: Report truthful GraphQL vector capability and qualified search availability

Linear: [OVE-146](https://linear.app/overtonbell/issue/OVE-146/ksp-g08-report-truthful-graphql-vector-capability-and-qualified-search)

Status: ready-for-agent; implementation not started.

## What to build

The product sees either a qualified selected vector/phrase search capability or an explicit supported exclusion.

Owner: Biotech search and GraphQL owners.

## Acceptance criteria

- [ ] Separate configured flag, index ONLINE state, compatible model/dimensions/similarity, populated coverage and authorized serving eligibility.
- [ ] If selected, qualify exact product indexes and supplied-vector versus provider phrase behavior with budgets; phrase encoding does not populate stored embeddings.
- [ ] If not selected, return unsupported without provider calls; v2 lacking @vector must not silently inherit original entity-vector endpoints.
- [ ] Keep DDL in reviewed deployment migrations, preserve legacy indexes until explicit transition and avoid credentials in logs or client exports.

## Blocked by

Q03, G01, N04

## Testing seam

Exercise the published consumer behavior and actual native adapter at the highest useful seam. Use targeted component, disposable integration and selected-query measurements; complete application fixtures remain restricted to F99.

## Out of scope

Implicit v2 acceptance, unreviewed ontology/vector choices, routing agents through GraphQL, unrelated refactors, and either complete application fixture before F99.
