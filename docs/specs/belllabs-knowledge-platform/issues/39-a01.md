# A01: Delegate a Research request to a durable mission and reconnect

Linear: [OVE-118](https://linear.app/overtonbell/issue/OVE-118/ksp-a01-delegate-a-research-request-to-a-durable-mission-and-reconnect)

Status: ready-for-agent; implementation not started.

## What to build

A user escalates a scoped knowledge gap to research and can reconnect, inspect progress or cancel through the product surface.

Owner: Product agent and Mission Control adapters.

## Acceptance criteria

- [ ] Inspect existing corpus and evidence gaps before external acquisition.
- [ ] Submit an admitted native request with immutable inputs, budget and exact capability bindings.
- [ ] Project authoritative mission/task progress with cursor replay after reconnect; do not reissue side effects from chat history.
- [ ] Keep execution completion, semantic hold, domain application and publication distinct.
- [ ] Cancellation and timeout reconcile already committed effects through native receipts.
