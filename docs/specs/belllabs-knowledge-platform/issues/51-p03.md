Linear: [OVE-122](https://linear.app/overtonbell/issue/OVE-122/ksp-p03-run-the-client-facing-deep-agent-with-both-domain-assemblies)

Status: ready-for-agent; implementation not started.

## What to build

A conversation uses the correct domain's guidance and tools, answers bounded questions quickly, and follows durable research tasks.

Owner: Product agent runtime owner.

## Acceptance criteria

- [ ] Configure application-specific skills/tool allowlists and route profiles from authenticated bindings.
- [ ] Use lightweight state for ordinary reads; instantiate a sandbox only when admitted work needs execution.
- [ ] Keep conversation state separate from mission authority and app-isolate checkpoints/memory.
- [ ] Exercise partial answers, skill loading, tool denial, budget escalation, reconnect and cancellation in component tests.
- [ ] The user sees evidence/route/task state; prompts cannot grant publication or cross-app authority.
- [ ] The Biotech client-facing Deep Agent uses native skills/read/ingest operations; it does not consume the product GraphQL SDK.
