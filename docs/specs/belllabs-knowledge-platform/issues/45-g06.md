## Acceptance criteria

- [ ] Freeze operation/data-cardinality/workload baseline and inspect generated Cypher with EXPLAIN and isolated PROFILE, preserving correct results.
- [ ] Measure supported filter/sort/pagination plans, index applicability and N+1 behavior only where custom resolvers exist.
- [ ] Measure build bytes/types/time, process RSS/heap, translation, pool wait, database/provider/serialization time, response bytes and p50/p95/p99/error/cost.
- [ ] Apply only demonstrated optimizations under reviewed compatibility; no blind enabling of all directives or automatic replacement of legacy indexes.
