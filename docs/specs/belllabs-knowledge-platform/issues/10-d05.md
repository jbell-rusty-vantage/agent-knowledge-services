# D05: Capture provider and fallback results with truthful evidence contracts

Linear: [OVE-98](https://linear.app/overtonbell/issue/OVE-98/ksp-d05-capture-provider-and-fallback-results-with-truthful-evidence)

Status: ready-for-agent; implementation not started.

## What to build

A domain agent acquires a source through an admitted upstream provider or an explicit lower-cost fallback and can verify what was captured.

Owner: Shared acquisition/preparation and domain guidance owners.

## Acceptance criteria

- [ ] Keep upstream skills/providers independently owned; adapters normalize custody, content, completeness and provenance where useful.
- [ ] Capture actual tool schemas/artifact versions and dependency requirements without credentials in manifests.
- [ ] Fallback HTTP/browser/parser selection is explicit; missing rendered content yields an incomplete result.
- [ ] Test provider timeout, partial content, unsupported media, duplicate capture and malformed outputs through published operations.
- [ ] Record provider cost/route and retain bytes for verification; no copied external tool becomes an unowned internal service.
